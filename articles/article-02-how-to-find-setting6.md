## 記事構成

### リード文（200字程度）
```
「高設定に座れない」「毎回低設定を掴む気がする」
その原因のほとんどは、ホール選びと台選びの基準が曖昧なことです。
この記事では、私が実践で使っている設定6を見抜くための3つのポイントを紹介します。
```

### 本文構成

1. **ポイント①：ホールの設定配分のクセを把握する**
   - 同じホールに通って傾向を掴む重要性
   - イベント日と非イベント日の差を記録する
   - データサイトの活用方法（※ツール名は適宜記載）

2. **ポイント②：機種ごとの設定差ポイントを知る**
   - ボーナス確率だけで判断しない
   - AT機・ART機それぞれの設定差が出る数値
   - 序盤で捨てるべきライン・続行すべきラインの目安

3. **ポイント③：シマ全体の動きを見る**
   - 高設定は1台だけでなくシマ単位で入ることが多い
   - 隣・周辺台の出方をチェックする
   - 開店直後の並び・ヘコみ台の位置を観察する

4. **実践での使い方（具体例）**
   - 上記3つを組み合わせた台選びの流れ
   - 実際に高設定を掴めた日の動き方を簡単に紹介

5. **まとめ**
   - 「データは嘘をつかない」の締め
   - 次回記事・有料マガジンへの誘導
